# overview

The Backend 2.0 NestJS API is implemented in `apps/api`. It covers verified local authentication, tenants and location grants, catalog, batches, FEFO sales/returns, waste, expiry, rules-based recommendations and basic analytics. The Express/MongoDB prototype remains in `legacy/` as a historical reference. Next.js frontend and Astro renderer are not implemented. See [README](../../../../README.md) and [domain](../../../../PRODUCT_DOMAIN.md).
